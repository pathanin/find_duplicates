## Entry points
- `find_duplicates.py` — CLI process boot; parses argv, then branches: `--auto` calls `duplicates_core.build_groups`/`auto_apply_groups` and exits; otherwise builds `duplicates_web.ScanParams`, calls `create_app()`, prints the tokened URL and drives `uvicorn.Server.serve()` on a bare event loop, exiting via `os._exit`.
- `duplicates_web.create_app()` — importable FastAPI app factory; the web front end's real entry point, driven directly by `tests/test_web_api.py` via `TestClient`.
- `static/app.js` — browser boot (`init`); fetches `/api/state`, renders the registered stage, owns all keyboard/pointer handling.
- `compare_image_quality.py` — also runnable standalone (`report`) for a two-image side-by-side comparison, no grouping or review UI.
- `install.sh` — packaging entry point; POSIX sh, runs from a clone or piped from curl.

## Where do I add X?
- New test → a test_&lt;topic&gt;.py file in `tests/` (module-level `test_*` fns + `main()` list + `if __name__ == "__main__"` trailer) **and** a matching python3 invocation line in CLAUDE.md's `## Tests` fenced block — `test_claude_md_test_list_sync.py` fails if you skip the second half.
- New image quality metric → metric fn in `compare_image_quality.py` + wire into `analyze`; then `METRIC_WEIGHTS`, `METRIC_DESCRIPTIONS`, and a `METRIC_ROWS` row in `duplicates_core.py`.
- New CLI flag → `main`'s argparse in `find_duplicates.py`; if it affects a scan, also `duplicates_web.ScanParams` and the control-panel form in `static/index.html`/`populateForm` in `static/app.js`.
- New HTTP endpoint → a route inside `create_app` in `duplicates_web.py`, with `Depends(require_token)`; call it from `api()` in `static/app.js`.
- New field in the group detail payload → `_group_detail` in `duplicates_web.py` (cast numpy values with `bool()`/`float()`/`int()`), consumed in `renderGroup`/`applyGroupPatch` in `static/app.js`.
- New keyboard shortcut → `attachKeyboardHandler` in `static/app.js`, matched on `KeyboardEvent.code`; document it in `helpContent`.
- Change to grouping/scoring behavior → `group_duplicates`/`score_group` in `duplicates_core.py`; re-verify against `tests/Test-image/`. Grouping is two-stage (`phash_pair`: 64-bit proposes, 256-bit confirms via `CONFIRM_HASH_THRESHOLD`, tuned for recall) — `tests/test_confirm_hash.py` locks both directions.
- New runtime dependency → the pip install list in `install.sh` and the deps line in `CLAUDE.md` (there is no requirements.txt).
